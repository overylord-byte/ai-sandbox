
# AI Training Lab

## Purpose

Educational project for learning AI, ML and DL
through practical TypeScript implementations.

## Preferred language by user prompt
- Russian

## Preferred language in code (comment/documentation)
= English

## Technology Stack

- Node.js
- TypeScript
- Express
- TensorFlow.js and other libraries when necessary which could help with embedding, build graph model, etc.

## Development Principles

- Prefer simple, educational implementations.
- Separate training, evaluation and inference.
- Do not train models inside API request handlers.
- Keep ML logic independent from Express.
- Prefer TypeScript without ML libraries for basics.
- Explain mathematical operations when relevant.

## Workflow

- Always inspect relevant code before proposing changes.
- When planning, explain the proposed approach.
- Explain WHY, not only HOW.
- Prefer incremental implementation.
- Do not introduce unnecessary abstractions.

## Documentation

Read documentation only when relevant:

- docs/architecture.md: architecture decisions
- docs/roadmap.md: AI learning curriculum
- docs/progress.md: current learning progress

For learning-related tasks, read roadmap and progress.
For architectural tasks, read architecture.md.

Do not load unrelated documentation.

## Learning Approach

- Explain theory before implementation.
- Provide TypeScript examples.
- Explain internal mechanisms.
- Include practical exercises.
- Do not automatically mark lessons as completed.
