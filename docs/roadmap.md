
# AI Learning Roadmap

## Goal

Progress from A0 to A5 in AI engineering,
combining theory, practical implementation
and understanding of internal mechanisms.

Primary language: TypeScript.

## Learning Method

Every level includes:

1. Theoretical knowledge
2. Internal mechanisms
3. Practical implementation
4. Engineering principles
5. Typical mistakes
6. Final assessment

A level is completed only after
passing its assessment.

---

## A0 — AI Fundamentals

Goal:
Understand basic AI and ML concepts.

Topics:
- AI vs ML vs DL vs Generative AI
- Training and inference
- Datasets, features and labels
- Supervised learning
- Unsupervised learning
- Reinforcement learning
- Neural networks fundamentals
- LLM fundamentals
- Overfitting and generalization
- AI lifecycle and limitations

Practice:
- Linear regression in TypeScript
- Simple neural network using TensorFlow.js
- Basic model evaluation

Assessment:
- Explain fundamental concepts
- Implement a simple ML example
- Explain training and inference
- Explain why models make mistakes

---

## A1 — LLM Fundamentals

Topics:

- Attention mechanism

---

## Assessment Rules

For each level:
- Theory must be understood.
- Practical exercise must be completed.
- Results must be explained.
- Typical mistakes must be discussed.
- Final assessment must be passed.

Do not automatically advance to the next level.
